# 典威 AI 行为分析运营平台原型

双击“启动原型.command”后会自动打开登录页。演示账号为 `admin`，密码为 `123456`，验证码已自动填入；登录后进入数据看板。也可以直接双击任意 HTML 页面查看。

## 平台入口

- `登录-AI行为分析运营平台.html`：平台登录页，支持账号、密码、验证码、密码显隐和登录校验。
- `首页-AI行为分析数据看板.html`：AI 行为分析数据看板，右上角“管理后台”可进入运营管理端。
- `管理后台-运营中心.html`：后台管理端，包含运营首页、告警中心、报表统计、设备管理、人员管理、算法规则和系统管理。
- 后台菜单支持多 Tab 打开、切换和关闭；告警中心支持条件查询、重置及处置入口，报表统计支持五类事件、关键指标及近7日明细展示。
- 管理后台右上角提供“退出登录”，点击后清除当前演示登录状态并返回登录页。

## 目录约定

- data：模拟数据和页面配置。
- files：视频、截图、导出文件。
- images：图片素材。
- plugins：第三方前端插件。
- resources：所有页面共用的 CSS 和 JavaScript。
- tools：打包、数据生成等辅助工具。
- 根目录 HTML：一个业务功能对应一个可独立打开的页面。

## 后续新增功能

1. 在根目录复制一份 HTML 文件并修改 data-page 标识。
2. 在 resources/js/app.js 中增加对应的页面渲染函数。
3. 在 resources/css/app.css 中增加页面样式。
4. 模拟数据统一写入 data/mock-data.js。
